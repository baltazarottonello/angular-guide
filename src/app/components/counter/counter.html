This button is for the child component, the value of the input is to way binding, when the child updates the value,
the value propagates to the parent, who renders the value.

Click the button and see the value above in the ModelInputs component template.

Implicit change events:

When you declare a model input in a component or directive,
Angular automatically creates a corresponding output for that model. Which can be listened to, and handled by a method declared in the parent component.
Click the button "Start counter" and open the DevTools to see the handler output.
